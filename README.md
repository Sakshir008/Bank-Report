# Bank Analysis using Microsoft Excel

## Introduction

This project analyzes a bank dataset using Microsoft Excel to understand
account-opening activity, branch performance, agent-wise performance,
and deposit patterns. The analysis uses structured banking records
containing account type, agent name, account-opening channel, branch,
customer category, month, transaction date, and deposited amount.

The goal is to summarize the data into meaningful findings that can help
identify account preferences, compare branch and agent performance, and
understand how deposits are distributed across account-opening channels.

## Objectives

-   Analyze the number of accounts across different account types.
-   Compare account-opening activity by agent.
-   Evaluate branch-wise account openings.
-   Analyze deposited amounts by agent and account-opening channel.
-   Compare account openings from new and existing customers.
-   Use Excel tools to organize, summarize, and communicate findings.
-   Identify areas that may warrant further investigation or operational
    attention.


## Analysis Performed

The report uses Excel data preparation and cleaning, filters and
conditional formatting for an initial review, and PivotTables and charts
to summarize the data by: - Account type and agent - Branch - Agent and
account-opening channel - Deposited amount by agent - New versus
existing customers

## Key Insights

### 1. Account type

-   **Checking** is the most common account type, with **289 records**.
-   **CD** accounts total **211 records**.
-   **Savings** accounts total **194 records**.
-   **IRA** is the least common account type, with **28 records**.

### 2. Agent performance

-   **Ashok Kumar** has the highest number of account records (**206**)
    and the highest total deposited amount (**₹19,10,665**).
-   **Sweta** has the lowest number of account records (**6**) and the
    lowest total deposited amount (**₹42,027**).

### 3. Branch performance

-   **Central:** 366 account records
-   **North County:** 200 account records
-   **Westside:** 156 account records

Central has the highest account-opening count in this dataset, while
Westside has the lowest.

### 4. Account-opening channel

-   Records associated with **New Accts** account for **₹43,57,711** in
    deposits (approximately **67.09%** of the total).
-   Records associated with **Teller** account for **₹21,37,464**
    (approximately **32.91%**).

### 5. New versus existing customers

-   **Existing customers:** 473 account records (approximately
    **65.5%**)
-   **New customers:** 249 account records (approximately **34.5%**)

Existing customers account for more records than new customers in this
dataset.

### 6. Deposit overview

-   **Total deposited amount:** ₹64,95,175
-   **Average amount per record:** approximately ₹8,996

The average is calculated as the total deposited amount divided by the
722 records; it represents an average per dataset record, not
necessarily per unique customer.

## Recommendations / Areas for Further Analysis

-   Investigate opportunities to increase new-customer acquisition while
    continuing to serve existing customers.
-   Review the differences in account-opening volumes across branches,
    especially North County and Westside, to understand whether local
    outreach or operational changes could help.
-   Study the reasons behind differences in agent-level account counts
    and deposited amounts before drawing conclusions about individual
    performance.
-   Investigate the low number of IRA records to understand customer
    demand and whether additional product awareness is appropriate.
-   Review the contribution of the Teller channel and explore whether
    process improvements could increase its account-opening activity.
-   Analyze monthly trends in more detail to identify possible seasonal
    patterns.

These are suggested follow-up actions based on the observed figures; the
dataset alone does not establish the causes of the differences.

## Conclusion

This Excel project summarizes 722 bank records and ₹64,95,175 in
deposited amounts. The analysis shows that Checking is the most frequent
account type, Central has the highest branch-wise account count, Ashok
Kumar has the highest agent-wise account count and deposited amount, New
Accts represents the larger share of deposits, and existing customers
account for more records than new customers.

The project demonstrates how Excel can turn structured transaction data
into understandable summaries that support further investigation and
data-informed banking decisions.
